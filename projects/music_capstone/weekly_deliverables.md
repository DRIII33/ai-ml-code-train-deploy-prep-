# Weekly Deliverables Map

This project is built as a cumulative portfolio and capstone sequence.

| Week | Focus | Deliverable |
|---:|---|---|
| 1 | Python fundamentals and context building | Music data profile and Python-ready environment checklist |
| 2 | Data wrangling with pandas | Cleaned dataset and feature schema |
| 3 | SQL and APIs | Queryable music data tables |
| 4 | Project 1 | Data wrangling report and quality log |
| 5 | Statistics | Bias and engagement summary report |
| 6 | Experimental design | A/B test and fairness evaluation plan |
| 7 | Visualization | Dashboard of discovery trends and fairness gaps |
| 8 | Regression | Popularity and engagement baseline model |
| 9 | Project 2 | EDA and long-tail discovery analysis |
| 10 | Classification | Artist/track fit classifier |
| 11 | Scikit-Learn | Fairness-aware model comparison |
| 12 | Project 3 | Ranking system prototype |
| 13 | Deep learning and embeddings | Audio/artist similarity model |
| 14 | Advanced methods | Exploration-exploitation recommender |
| 15 | MLOps | Deployed versioned model package |
| 16 | Capstone final | Executive presentation and research brief |

## Capstone narrative

Across all weeks, students will evaluate the same business problem: how to improve discovery while mitigating popularity bias in a music streaming ecosystem.
