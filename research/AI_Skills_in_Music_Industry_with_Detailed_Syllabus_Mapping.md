The operational flow of these recommendation systems begins with raw audio ingestion and acoustic feature extraction utilizing tools like Librosa or Torchaudio to compute Short-Time Fourier Transforms (STFT) and Mel spectrograms. These extracted acoustic features are fed into candidate generation systems, primarily Two-Tower Neural Networks, where track features and user interaction vectors are transformed into dense latent embeddings.In the candidate generation phase, the User Tower accepts real-time user interaction sequences, demographic indicators, context (time of day, device), and long-term listening histories to compute a dense user vector $U \in \mathbb{R}^d$. Simultaneously, the Track Tower offline-computes dense track embeddings $I \in \mathbb{R}^d$ utilizing acoustic features, lyric natural language processing (NLP) representations, and collaborative filtering signals. Affinity scoring between a user and a candidate track is calculated via the vector dot product or cosine similarity:$$\text{Score}(U, I) = U \cdot I = \sum_{k=1}^{d} U_k I_k$$Because track embeddings $I$ are static, they are pre-indexed into spatial data structures, such as Hierarchical Navigable Small World graphs via FAISS. At inference time, the user tower generates $U$, and an Approximate Nearest Neighbor (ANN) search retrieves top candidates with sub-10-millisecond latency. Retrieved candidates pass into a multi-stage heavy ranking pipeline where light pre-rankers and heavy cross-encoders evaluate complex feature interactions between the user and specific track attributes. Finally, real-time diversity and business logic filters adjust candidate rankings to enforce genre diversity, apply anti-fraud filters, prevent recommendation echo chambers, and comply with chart eligibility regulations.Advanced architectures incorporate Heterogeneous Graph Neural Networks (2T-HGNN), where co-listening graphs link disparate content nodes (tracks, podcasts, audiobooks) across shared user listening edges.
